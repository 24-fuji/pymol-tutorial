# 付録: 名前の一覧と調べ方

PyMOL をコマンドで操作するときは、**残基名・残基番号・鎖・原子名** などの名前を指定する必要があります。このページには、チュートリアルで使う名前の一覧と、知らない名前を調べる方法をまとめています。

課題で手が止まったら、操作の前に「何という名前で選べばよいか」をこのページで確認してください。

---

## 名前の組み立て

PyMOL では、原子 1 つ 1 つが次の名前を持っています。

| 名前 | 選択での書き方 | 例 |
| --- | --- | --- |
| オブジェクト名 | オブジェクト名そのもの | `2a65` |
| 鎖 (chain) | `chain` | `chain A` |
| 残基名 (3 文字) | `resn` | `resn ASP`、`resn HOH` |
| 残基番号 | `resi` | `resi 25` |
| 原子名 | `name` | `name CA`、`name OD1` |
| 元素 | `elem` | `elem O` |

まとめて書くと、`/オブジェクト//鎖/残基番号/原子名` (例: `/1hsg//A/25/OD1`) になります。

---

## 名前を調べる方法

### ビューアでクリックする

原子をクリックすると、ログにその原子の名前が表示されます。

```
 You clicked /1hsg/A/A/ASP`25/OD1
```

`ASP` が残基名、`25` が残基番号、`OD1` が原子名です。

### 配列を表示する

メニューの `Display` → `Sequence` で、ビューアの上に配列が表示されます。タンパク質の残基は 1 文字表記で、それ以外の分子 (リガンド、イオン、水) は残基名で並びます。クリックすると選択されます。

### コマンドで一覧を出す

```
# 鎖の一覧
print(cmd.get_chains("2a65"))

# 特定の残基の原子名の一覧
iterate 2a65 and resi 179, print(resn, resi, name)
```

タンパク質・水以外の分子 (リガンド、イオンなど) を、1 分子 1 行で一覧にするには、次の Python を `.pml` に書くか、コマンドラインに貼り付けます。

```
python
seen = set()
cmd.iterate("not polymer and not solvent", "seen.add((resn, chain, resi))", space={"seen": seen})
for r in sorted(seen): print(*r)
python end
```

2a65 では次のように表示されます (残基名、鎖、残基番号)。

```
BOG A 701
BOG A 702
BOG A 703
BOG A 704
BOG A 705
CL A 753
LEU A 601
NA A 751
NA A 752
```

### PDB のウェブページで調べる

RCSB PDB (`https://www.rcsb.org/structure/2A65` のように PDB ID を付けた URL) の「Small Molecules」の欄に、その構造に含まれる低分子の残基名 (ID) と正式な名前が載っています。

### 原子名の読み方

| 原子名 | 意味 |
| --- | --- |
| `N`、`CA`、`C`、`O` | 主鎖の原子 (N: アミノ基の窒素、CA: α 炭素、C: カルボニル炭素、O: カルボニル酸素) |
| 1 文字目 | 元素 (C、N、O、S) |
| 2 文字目 | α 炭素からの位置。B (β)、G (γ)、D (δ)、E (ε)、Z (ζ)、H (η) の順に遠くなる |
| 3 文字目の数字 | 同じ位置に複数あるときの番号 (例: `OD1` と `OD2`) |

例えば、Asp の側鎖のカルボキシ基の酸素は `OD1` と `OD2`、Asn の側鎖アミド基の窒素は `ND2` です。

**側鎖だけ** を選ぶときは、主鎖の原子を除きます。

```
resi 25 and not name N+C+O        # CA は残す (リボンと側鎖がつながって見える)
resi 25 and not name N+CA+C+O     # CA も除く
```

## よく出る、タンパク質以外の分子

| 残基名 | 名前 | 補足 |
| --- | --- | --- |
| `HOH` | 水 | 結晶構造では、酸素原子だけが記録されていることが多い |
| `NA` | ナトリウムイオン (Na⁺) | |
| `CL` | 塩化物イオン (Cl⁻) | |
| `K` | カリウムイオン (K⁺) | |
| `MG` | マグネシウムイオン (Mg²⁺) | |
| `CA` | カルシウムイオン (Ca²⁺) | **原子名 `CA` (α 炭素) と同じ文字** なので、`resn CA` と `name CA` を取り違えないこと |
| `ZN` | 亜鉛イオン (Zn²⁺) | |
| `HEM` | ヘム | 中心の鉄の原子名は `FE` |
| `PO4` | リン酸イオン | |
| `SO4` | 硫酸イオン | 結晶化の溶液に由来することが多い |
| `GOL` | グリセロール | 結晶化・凍結保護剤に由来することが多い |
| `EDO` | エチレングリコール | 同上 |

> 低分子 (リガンド) の残基名は、PDB が化合物ごとに付けた 1〜3 文字 (または 5 文字) の ID で、構造ごとに違います。`MK1` や `21B` のように、名前から中身が推測できないものも多いので、上の「名前を調べる方法」で確認してください。

### 分子の種類で選ぶキーワード

| キーワード | 選ばれるもの |
| --- | --- |
| `polymer` | タンパク質と核酸 |
| `organic` | タンパク質・核酸以外の有機分子 (リガンド、界面活性剤など) |
| `inorganic` | 無機物 (イオンなど) |
| `metals` | 金属イオン |
| `solvent` | 水 |
